# To-Do List App

A simple, responsive To-Do List web app built with vanilla JavaScript, HTML, and CSS. Tasks are saved in the browser's `localStorage`, so your list persists even after refreshing the page.

## Features

- Add new tasks
- Mark tasks as complete (click to toggle a strikethrough + checkmark icon)
- Remove tasks with a single click on the "×" icon
- Data persists across page reloads using `localStorage`
- Clean, responsive UI with a gradient background

## Tech Stack

- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla JS, DOM Manipulation)

## Usage

- Type a task in the input field and press **Enter** or click **Add**.
- Click on a task to mark it as completed.
- Click the **×** next to a task to delete it.
