# To-Do List App

A simple, responsive To-Do List web app built with vanilla JavaScript (ES6+), HTML, and CSS. Tasks are saved in the browser's `localStorage`, so your list persists even after refreshing the page.

## Features

- Add new tasks
- Mark tasks as complete (click to toggle a strikethrough + checkmark icon)
- Remove tasks with a single click on the "×" icon
- Data persists across page reloads using `localStorage`
- Clean, responsive UI with a gradient background

## Tech Stack

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6+, ES Modules, Arrow Functions, Destructuring)
